# AI Object Detection and Tracking

## Overview
A computer vision application that detects and tracks objects in uploaded videos using YOLOv8 and ByteTrack.

## Technologies Used
- Python
- Streamlit
- OpenCV
- YOLOv8
- ByteTrack

## Features
- Upload video files.
- Detect objects using YOLOv8.
- Track objects using ByteTrack.
- Display processed video.
- Download processed video.

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Application

streamlit run app2.py

## Model
The application uses YOLOv8n (yolov8n.pt).
The model is downloaded automatically on the first run if it is not available locally.
