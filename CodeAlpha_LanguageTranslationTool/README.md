Language Translation Tool

1. What is this project?
This project is a simple language translation application that converts text from one language into another.

2. Why did I build this project?
I built this project to understand how translation APIs work and how Python can be used to develop useful language applications.

3. What can this application do?
Users can enter text, select the source and target languages, and translate the text into their preferred language.

4. Which technologies did I use?
- Python
- Streamlit
- Deep Translator
- Google Translate API

5. How does it work?
First, the user enters text and selects the languages. The application sends the text to the translation service and displays the translated result.

6. How can I run this project?

Install the required libraries:

`pip install -r requirements.txt`

Run the application:

`python -m streamlit run app.py`

7. What did I learn from this project?
I learned how to use translation libraries, work with APIs, handle user input, and build a simple web application using Streamlit.
